# Название проекта

Описание проекта: Проект предназначен для анализа транзакций, получения курсов валют и цен на акции, а также генерации отчетов.

## Установка

1. **Клонируйте репозиторий:**
bash
  

2. **Создайте и активируйте виртуальное окружение:**
bash
   python -m venv venv
   source venv/bin/activate  # На macOS/Linux
   venv\Scripts\activate  # На Windows
   

3. **Установите зависимости:**

   Если вы используете `poetry`, выполните:
bash
   poetry install


   Если используете `requirements.txt`, выполните:
bash
   pip install -r requirements.txt
   

## Использование

1. **Запуск основного скрипта:**

   Для генерации отчета выполните:
bash
   python src/main.py


2. **Тестирование:**

   Запустите тесты, чтобы убедиться, что все работает корректно:
bash
   pytest tests/


## Конфигурация

- **Файл `.env`** используется для хранения конфиденциальных данных, таких как ключи API.
- Используйте `.env_template` в качестве шаблона для создания вашего `.env` файла.
